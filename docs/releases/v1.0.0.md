# AtomicHeart-AR 1.0.0

**Publication status: BLOCKED — the three approved p12 release PAKs must be supplied
and verified before publishing a playable download.**

The source tree and release notes are prepared for 1.0.0. A source archive is not
an installable localization package. The existing GitHub release tagged `0` must
not be treated as evidence that these assets have been uploaded.

## ملاحظات الإصدار

تعريب مجتمعي للعبة **Atomic Heart على الحاسب / Steam**، مبني على مجموعة
`p12 + font v3 + tips_x150` الموثّقة في تقارير المشروع.

- 27,618 صفًا في القاعدة الرئيسية، منها 26,717 صفًا عربيًا و458 صفًا تحتفظ
  بالأسماء الإنجليزية. توجد 443 حالة غير مترجمة ضمن فئة النسخ.
- أسماء الأسلحة والعناصر تبقى بالإنجليزية، مع تعريب الأوصاف والتلميحات.
- تعريب 1,140 تسمية متحدث `P-3` إلى **«الرائد»**.
- خط v3 وحزمة تلميحات `tips_x150`؛ المتغير التجريبي `p12g` خارج الحزمة الافتراضية.
- README عربي بتصميم جديد وروابط للتثبيت والتحقق والمساهمة.

### التثبيت

أغلق اللعبة، واحتفظ بنسخة احتياطية من `~mods`، ثم انسخ ملفات `.pak` الثلاثة من
حزمة التعريب إلى:

```text
...\Atomic Heart\AtomicHeart\Content\Paks\~mods
```

اختر **Korean / الكورية** من **Text Language** داخل اللعبة. الصوت الإنجليزي
يبقى كما هو. لإزالة التعريب، أغلق اللعبة واحذف ملفات الحزمة الثلاثة فقط واستعد
نسختك الاحتياطية. [التعليمات الكاملة](../../README.md#التثبيت).

### القيود

قد تبقى بعض مشاكل توقيت الترجمة النصية والتراكب أو قصّ أربعة أسطر. نسخة اللعبة
الموثّقة هي Steam build `24534183`؛ لا يوجد في هذه التعديلات اختبار جديد لنسخ
أخرى. راجع [المشاكل المعروفة](../../KNOWN_ISSUES.md).

## Maintainer: assemble the download

Use the three approved files listed in [SHA256SUMS](v1.0.0-SHA256SUMS.txt).
Their exact sizes and hashes come from [the recorded install verification](../../reports/install_verification.md).
Verify the actual files against both references before packaging. Older or third-party
packages are not substitutes for this approved set.

Prepare `AtomicHeart-AR-v1.0.0/` with:

```text
AtomicHeart-AR-v1.0.0/
  zzz_atomicheart-ar_carrier_koKR_p12_P.pak
  zzz_atomicheart-ar_font_p3_unhinted_P.pak
  zzz_atomicheart-ar_tips_x150_P.pak
  INSTALL.txt
  SHA256SUMS.txt
  LICENSE
  THIRD_PARTY_LICENSES.md
```

Put the Arabic installation/removal instructions above in `INSTALL.txt`, and copy
`v1.0.0-SHA256SUMS.txt` as `SHA256SUMS.txt`. Do not copy an installed user's
`atomic-heart-ar-install-manifest.json`: it describes that machine's installation,
not a portable release. Include notices for all redistributed components; confirm
the font composition and applicable notices from the actual font payload.
Do not bundle original game archives, executables, DLLs, or third-party tool binaries.

Compress the prepared directory as `AtomicHeart-AR-v1.0.0.zip`. Reopen the ZIP and
verify that all three extracted PAK hashes still match. Generate a separate SHA256
for the ZIP after packaging; the reference file describes PAKs, not the future ZIP.

2. Verify and prepare the download as described above. Existing reports are historical
   evidence; do not describe the repackaged archive as newly play-tested without a test.
3. Create a release with tag **`v1.0.0`**, targeting the reviewed commit on `main`,

4. Use the Arabic release notes, installation instructions, and limitations above as
   the release body. Attach the verified ZIP and its checksum file.
5. Publish only after the attachments are present. Update the README's preparation

Publishing a release on the upstream repository requires repository write
access. A contributor fork and a pull request alone do not grant that access.
