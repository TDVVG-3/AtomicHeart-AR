# تعريب Atomic Heart · 1.0.2

تطبيق عربي لويندوز ولينكس مع حزمة التعريب المصحّحة، وفحص الملفات والترقية والإزالة من نافذة واحدة.

## أي ملف أنزّل؟

- **Windows:** حمّل `AtomicHeart-AR-1.0.2-win-x64.zip`، وفك الضغط وشغّل `AtomicHeartAR.exe`. اترك مجلد `payload` بجانبه.
- **Linux / Steam Proton:** حمّل `AtomicHeart-AR-1.0.2-linux-x86_64.AppImage`، وامنحه إذن التشغيل وافتحه في وضع سطح المكتب.
- **تركيب يدوي:** حمّل `AtomicHeart-AR-1.0.2-payload.zip` وانسخ ملفات PAK الثلاثة إلى `AtomicHeart/Content/Paks/~mods` بعد إغلاق اللعبة.

التطبيقان يتضمنان التعريب و.NET؛ لا تحتاج تثبيت بيئة تشغيل إضافية. أغلق اللعبة، واختر مجلدها في التطبيق وثبّت التعريب، ثم اختر **Korean / الكورية** للغة النص داخل اللعبة.

```sh
chmod +x AtomicHeart-AR-1.0.2-linux-x86_64.AppImage
./AtomicHeart-AR-1.0.2-linux-x86_64.AppImage
```

إذا تعذّر تركيب AppImage عبر FUSE، أضف `--appimage-extract-and-run` إلى أمر التشغيل.

## الجديد

- AppImage أصلي للينكس بواجهة عربية، مع اكتشاف مكتبات Steam العادية وFlatpak.
- ثمانية نصوص مصحّحة داخل الحزمة الفعلية، منها «الأسلحة البيضاء»، و«نقاط الضعف»، ومدة انتظار القدرة، وصيغة خطاب خاريتون.
- ترقية مجموعة p12 المعروفة مع استرجاع الملفات السابقة عند فشل التحديث؛ رفض الملفات المعدّلة والحزم المتعارضة.
- إصلاح أدوات حساب توقيت الترجمة وتدقيق الخطوط، وتوثيق أدق لحدود HUD.
- README جديد وخطوات تشغيل وتحديث وفحص واضحة.

اجتازت عملية التجهيز 27 اختبارًا على ويندوز، و31 على لينكس، و18 لأدوات التوقيت والخط، مع تشغيل نافذة AppImage وفحص حزمة التعريب بعد إعادة بنائها.

## التوافق والحدود

Windows x64، أو Linux x86_64 ببيئة متوافقة مع Ubuntu 22.04 / glibc 2.35+ وX11 أو XWayland وخط عربي مثل DejaVu Sans. لم يُختبر جهاز Steam Deck فعليًا.

الحزمة المستقرة مبنية على p12 مع تصحيحات النص؛ **متغير p12g التجريبي غير مرفق**. قصّ بعض أسطر HUD ومشكلات التراكب التابعة لبيانات اللعبة ما زالت تحتاج اختبارًا داخل اللعبة. اللعبة نفسها غير مرفقة.

ملفات `.sha256` مرفقة للتحقق من سلامة التنزيلات. يوجد شرح قبل وبعد ونتائج الفحوص في [طلب الإصدار #5](https://github.com/TDVVG-3/AtomicHeart-AR/pull/5).
