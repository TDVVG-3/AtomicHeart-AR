# AtomicHeart-AR 1.0.3

الإصدار العام التالي بعد `1.0.0`: حزمة التعريب العربية المستقرة `p12` مع ثمانية
تصحيحات نصية، وحزمة `p12g` التجريبية للمقارنة. البنيتان الداخليتان `1.0.1`
و`1.0.2` لم تُنشرا كإصدار عام؛ `1.0.3` هو أول نشر عام بعد `1.0.0`.

## ما الجديد منذ 1.0.0

- ثمانية تصحيحات نصية عربية في قاعدة الترجمة وحزمة `p12`:
  - «الأسلحة البيضاء» بدل «الأسلحة الباردة» في تلميح القفز.
  - «تؤدّي إصابة النسيج الرخو…» في موضعين.
  - «فتبقى الروبوتات معطّلة» بدل «فيبقى».
  - تصحيح تسمية `Secateur` وأسماء عناصر داخل جمل.
  - تصحيح صياغة تلميح التمنّي وتسمية نقاط الضعف.
- أُعيد بناء حامل `p12` بالكامل ليشمل التصحيحات الثمانية؛ تغيّرت بصمته وبقي اسم
  الملف كما هو لتسهيل الترقية.
- حامل `p12g` التجريبي يحتفظ بسلوك التوقيت المعتمد في `1.0.0` مع إضافة التصحيحات
  النصية نفسها فقط.
- أُصلح مدقّق قواعد الإصلاح `scripts/verify_text_fixups.ps1` ليفهم القواعد
  المقيّدة بالخلية والتسمية، والقواعد الملغاة، وقواعد `p11f` الخاصة.
- حُدّثت تقارير الفحص والوثائق، وأُضيف سكربت تغليف `1.0.3` مع تحقق من البصمات.

## التركيب

1. أغلق Atomic Heart بالكامل.
2. خُذ نسخة احتياطية من مجلد `~mods` إن كان موجودًا.
3. انسخ ملفات PAK الثلاثة فقط إلى:

   ```text
   ...\Atomic Heart\AtomicHeart\Content\Paks\~mods
   ```

4. داخل اللعبة اختر **Korean / الكورية** من **Text Language**. التعريب يستبدل
   خانة النص الكورية؛ الصوت الإنجليزي لا يتغيّر.
5. أعد تشغيل اللعبة إذا لم يظهر النص العربي مباشرة.

## إلغاء التثبيت

احذف ملفات PAK الثلاثة المذكورة أعلاه فقط من `~mods`، ثم استعد نسختك الاحتياطية
عند الحاجة. لا تحذف أي PAK أصلي من اللعبة ولا أي ملف خارج `~mods`.

## p12 مقابل p12g

- **p12**: الإصدار المستقر الافتراضي والمُوصى به. هذه هي الحزمة الأساسية.
- **p12g**: إصدار تجريبي يطبّق تعديلات توقيت H1/H2/H3 على الترجمة.
- لا تضع الحاملين `p12` و`p12g` معًا في `~mods`؛ اختر واحدًا فقط.
- إذا ظهرت مشكلة توقيت مع `p12g`، استخدم حزمة `p12`.

## القيود المعروفة

- توقيت الترجمة مرتبط بملفات الصوت الأصلية، وقد تتراكم السطور في الحوارات السريعة.
- قد تُقصّ السطور عند ظهور أربعة سطور في الشريط السفلي.
- رقم الاختيار «1 //» يظهر على الجانب الأيسر في بعض القوائم.
- توجد 343 سطرًا من نوع H3 بلا مدة مقطع صالحة في `p12g`.
- لم يُعد اختبار العرض البصري داخل اللعبة ولا على جهاز Steam Deck ضمن هذا الإصدار.
- لا يحل هذا الإصدار مشاكل واجهة اللعبة الأصلية أو تخطيط HUD.

# AtomicHeart-AR 1.0.3 (English)

The next public release after `1.0.0`: the stable Arabic `p12` localization package
with eight text corrections, plus the experimental `p12g` timing build. Internal
builds `1.0.1` and `1.0.2` were never published as public releases; `1.0.3` is the
first public release after `1.0.0`.

## Changes since 1.0.0

- Eight Arabic text corrections in the master database and the `p12` carrier:
  cold-weapon naming ("white weapons"), two subject-verb corrections, the robot
  plural agreement, `Secateur` and in-sentence item names, a wish-tooltip phrasing
  fix, and a weakness-label fix.
- The `p12` carrier was rebuilt from the corrected master. The file name is unchanged
  for upgrade compatibility; its SHA256 changed.
- The experimental `p12g` carrier keeps the `1.0.0` timing behavior and adds only the
  same eight text corrections.
- `scripts/verify_text_fixups.ps1` now understands cell-scoped and label-scoped rules,
  superseded global rules, and p11f-only timing rules.
- Reports and documentation were refreshed; `scripts/package_release_1_0_3.ps1`
  packages the gated payloads with hash checks.

## Install

1. Close Atomic Heart completely.
2. Back up the game's `Paks\~mods` folder if it exists.
3. Copy only the three PAK files into:

   ```text
   ...\Atomic Heart\AtomicHeart\Content\Paks\~mods
   ```

4. In the game settings, set **Text Language** to **Korean**. The mod replaces the
   Korean text slot; English voice audio is unchanged.
5. Restart the game if the Arabic text does not appear immediately.

## Uninstall

Remove only the three PAK files above from `~mods`, then restore your backup if needed.
Do not delete any stock game PAK or any file outside `~mods`.

## p12 vs p12g

- **p12**: stable default, recommended. This is the main package.
- **p12g**: experimental H1/H2/H3 subtitle-timing build.
- Do not install both carriers in `~mods`; use one only.
- If `p12g` shows timing problems, use the `p12` package.

## Known limitations

- Subtitle timing is tied to the original audio clips; lines can stack during fast
  dialogue exchanges.
- The bottom bar can clip lines when four lines are visible.
- The choice number "1 //" appears on the left side in some menus.
- 343 H3 rows have no usable clip duration in `p12g`.
- In-game visual rendering and Steam Deck hardware were not retested for this release.
- Original game UI and HUD layout limitations remain.
