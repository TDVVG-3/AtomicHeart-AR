# AtomicHeart-AR 1.0.1 · تطبيق تركيب التعريب

**حالة النشر:** التطبيق جاهز للبناء والتغليف؛ نشر GitHub Release ينتظر صلاحية الكتابة على المستودع الأصلي.

## الجديد

- تطبيق Windows بواجهة عربية وألوان مستوحاة من عالم Atomic Heart.
- نسخة كاملة تجمع التطبيق مع حزم `p12 + font v3 + tips_x150` من إصدار المشروع 1.0.0.
- اختيار مجلد اللعبة، واكتشاف مكتبات Steam، والتحقق من الملفات قبل التركيب.
- تثبيت وفحص وإزالة التعريب من واجهة واحدة، دون تشغيل سكربتات PowerShell القديمة.
- تحقق من الحجم وSHA256، ومنع المسارات التي تتجاوز مجلد التثبيت.
- الحفاظ على المودات الأخرى، واسترجاع الملفات عند فشل عملية التثبيت أو الإزالة.
- رفض حذف ملف تغيّر بعد تثبيته، مع الاحتفاظ بسجل التثبيت.

## الاستخدام

1. فك ضغط النسخة الكاملة؛ اترك مجلد `payload` بجانب `AtomicHeartAR.exe`.
2. أغلق اللعبة وشغّل التطبيق، ثم اختر مجلد Atomic Heart.
3. اضغط **فحص الملفات** ثم **تثبيت التعريب**.
4. اختر **Korean / الكورية** من إعداد لغة النص داخل اللعبة.

الصوت الإنجليزي يبقى كما هو. هذه نسخة من تطبيق التركيب؛ بيانات التعريب هي مجموعة p12
المعتمدة نفسها، والمتغير التجريبي p12g غير مرفق.

التطبيق يعمل على Windows x64 ويشمل بيئة .NET اللازمة. الملف التنفيذي غير موقّع رقميًا.
بصمة حزمة p12 الأصلية: `813ac0e3b6c51034de33ae08109567a44bb3655e5d1aff39420999a0e94f00dd`.
بصمة ملف ZIP الجديد تُولّد بعد التغليف وتُنشر بجانبه.

## التحقق

اختبارات محرك التثبيت تستخدم مجلدات لعبة وهمية؛ وتشمل التثبيت الأول، وتكراره، والإزالة،
وحماية الملفات المعدلة والمودات الأخرى، ورفض السجلات غير الصالحة، والاسترجاع عند الفشل.
توجد أيضًا دورة تركيب وفحص وإزالة بالحزم الرسمية داخل مجلد لعبة وهمي.

عرض العربية داخل اللعبة والتشغيل الفعلي للعبة لم يُختبرا في هذا الإصدار. توقف فحص الواجهة
البصري بطلب المستخدم؛ لا تُقدَّم صور تصميم README كأنها لقطات اختبار من اللعبة.

## للمشرف

```powershell
dotnet run --project app/AtomicHeartAR.Tests -c Release -- C:\temp\ah-ar-tests C:\downloads\p12
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package_installer.ps1 -PayloadZip C:\downloads\AtomicHeart-AR-1.0.0-p12.zip
```

بعد مراجعة ودمج مصدر التطبيق، أنشئ tag باسم `v1.0.1` على commit الذي يحتويه، وارفع
`AtomicHeart-AR-1.0.1-win-x64.zip` وملف `.sha256` المجاور له. حدّث حالة النشر وروابط README
بعد التأكد من ظهور المرفقات. لا تنشر إصدارًا يستهدف commit لا يحتوي مصدر التطبيق.
