# Contributing

This project is in the investigation phase. Contribution guidelines will expand
as the pipeline matures. Baseline rules:

1. The game installation is read-only. Never write to, move, or delete game files.
2. Never modify or distribute EXE/DLL/DRM/Steam files.
3. Never remove the English source text from any database or reference file.
4. All code, comments, filenames, and script output must be in English.
5. Download tools only from official upstream sources (see `tools/tools.lock.json`).
6. Do not commit game assets, PAKs, EXEs, or large raw dumps.
7. Record major technical decisions in `DECISIONS.md`.
8. Never claim a feature works without test evidence (NOT TESTED / PASS / FAIL / PARTIAL / BLOCKED).

## Translation contributions

Not open yet. When the master database exists, translations go into
`localization/master/atomic-heart-ar.tsv` following `docs/TRANSLATION_GUIDE.md`.
